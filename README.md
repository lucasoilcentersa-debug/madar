# مدار — سجل العملاء اليومي

واجهة عربية للفريق: كتابة الخدمة والمدينة بحرية، وحفظ مشترك في Supabase وتقرير مستقل لكل يوم بتوقيت السعودية. لا توجد بيانات تجريبية أو ارتباط بقوقل شيت.

## دخول الموظفين

الدخول مباشر برابط خاص يحتوي على مفتاح عشوائي، دون بريد أو كلمة مرور. أي شخص يمتلك الرابط يستطيع قراءة السجل وإضافة تسجيلات؛ لذلك يُشارك مع الموظفين فقط. الرابط الخاص ليس ضمن هذا المستودع.

مفتاح الوصول في جزء الرابط بعد #، ولا يُرسل إلى استضافة GitHub. بعد فتح الصفحة يُنقل إلى جلسة التبويب ويُزال من شريط العنوان. استخدم الرابط الخاص الأصلي لفتح المنصة لاحقًا أو من جهاز جديد. نسخ الرابط من شريط العنوان بعد إزالة المفتاح لن ينقل صلاحية الوصول.

المفتاح الموجود في config.js عام ولا يتيح قراءة السجلات بمفرده. طلبات السجل تتطلب أيضًا مفتاح الرابط الخاص. الوصول المباشر إلى الجداول مرفوض.

## الاستخدام

- كل تسجيل يساوي عميلًا واحدًا.
- الوقت والتاريخ من قاعدة البيانات بتوقيت السعودية. كل تاريخ له تقرير مستقل. اختيار تاريخ سابق لا يغير تاريخ التسجيل الجديد.
- نسبة المدينة = عدد تسجيلاتها ÷ إجمالي اليوم × 100. قد يختلف مجموع النسب المعروضة قليلًا عن 100 بسبب التقريب.
- البيانات مشتركة بين الأجهزة، وتتحدث كل 15 ثانية عندما تكون الصفحة ظاهرة، أو بزر تحديث التقرير.
- إعادة محاولة نفس الطلب بعد تعثر الاتصال لا تنشئ سجلًا مكررًا.
- البيانات الفعلية لا تُحفظ في GitHub أو داخل المتصفح. جلسة التبويب تحتفظ بمفتاح الوصول فقط.

## الاستضافة

ملفات الواجهة: index.html وapp.js وconfig.js وfavicon.svg و.nojekyll. لا تحتاج بناءً أو تثبيت حزم.

ارفع المجلد إلى GitHub. للنشر من Settings ثم Pages اختر Deploy from a branch ثم main و/(root)، أو اربط المستودع باستضافة ملفات ثابتة أخرى. توفر GitHub Pages المجاني يعتمد على نوع الحساب وظهور المستودع.

## قاعدة البيانات

تم تطبيق database.sql ثم team-access.sql على مشروع Supabase المرتبط. لا تُعد تشغيلهما في المشروع الحالي. في مشروع جديد يطبقان بهذا الترتيب، ثم تضاف تجزئة SHA-256 لمفتاح وصول عشوائي آمن في madar_link_keys. لا تنشر أصل مفتاح الرابط في ملف أو مستودع.

الجداول تبدأ فارغة. صلاحية الاستخدام في هذه النسخة تعتمد على الرابط الخاص، ولا تعتمد على حسابات الموظفين. تستطيع إيقاف الرابط بتغيير active إلى false في صفه داخل madar_link_keys، ثم إصدار رابط جديد عند الحاجة.
